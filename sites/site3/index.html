webserv — CGI demo

Static HTML/CSS served directly, forms below hand off to CGI scripts.

1. GET request → CGI

Submitting this sends your name in the query string. The server runs cgi-bin/greet.py, which reads QUERY_STRING and prints an HTML response.

2. POST request → CGI

Submitting this sends the message in the request body. The server runs cgi-bin/guestbook.py, which reads CONTENT_LENGTH bytes from stdin.

3. Broken CGI → error handling

This deliberately points at a script that crashes, to show the server returns a clean error instead of hanging or crashing itself.
